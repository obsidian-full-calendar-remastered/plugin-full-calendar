## Your voice is important!

As a solo developer, it is very easy to get stuck in the "GitHub echo chamber" and only hear from highly technical power users. To make Full Calendar better for *everyone*, I need to know which features are actually being used (e.g., should I focus on CalDAV sync, or optimize NLP?).

**If you choose to share your stats, here is exactly what happens:**
1. **What is sent:** Only the anonymous, aggregate numbers seen in the **payload below**. **No vault names, no file paths, no event titles, and no personal data.**
2. **The Pipeline:** Your payload passes through a Cloudflare Worker (strictly to prevent bot spam/DDoS) and lands in a self-hosted, open-source **Umami** analytics server in EU.
3. **Privacy First:** Umami is specifically built for privacy. No recording of IP address. No saving cookies. 

Because your privacy is paramount, **Obsidian will never send this automatically**. If you are willing to help guide the plugin's future, please copy the command below and run it in your computer's terminal. 

```bash
curl -X POST [https://fcr-cdn.plugin-fcr.workers.dev/telemetry](https://fcr-cdn.plugin-fcr.workers.dev/telemetry) \
  -H "Content-Type: application/json" \
  -d '{{JSON_PAYLOAD}}'
```
